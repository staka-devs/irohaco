# ADR-0010: バックアップと復元の明示操作

- 日付: 2026-10-18
- 状態: Accepted（SQLite参照設計を検証済み、Room/Android実機は未実装）
- 関連: `../database/DATABASE_DESIGN.md` / `../docs/implementation/USE_CASES.md` / ADR-0005（3NF必須）

## Context
完全ローカル既定と安全な機種変更を両立する。

## Decision
OS自動クラウドバックアップは既定無効。暗号化された手動エクスポートと、検証→候補照合→プレビュー→確認→適用→検査の段階復元を採用。原本・APIキー・外部送信許可・OS権限を既定で持ち運ばない。

## Consequences
機種変更時にユーザーがパスフレーズを管理し、復元時にプレビューを確認する手間が増える。その代わり、秘密情報や許可が意図せず持ち出されることを防ぐ。

## Rejected alternatives
無暗号化JSONを通常のDownloadsへ定期出力する方式、データベースファイルを無検証で置換する方式。
