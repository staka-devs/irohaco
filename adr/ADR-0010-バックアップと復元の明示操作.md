# ADR-0010: バックアップと復元は明示的な操作で行う

- 日付: 2026-10-18
- 状態: Accepted（SQLiteの参照設計は検証済み。Roomの実装とAndroid実機での検証は未実施）
- 関連: `../database/DATABASE_DESIGN.md`、`../docs/implementation/USE_CASES.md`、ADR-0005（3NF必須）

## Context
既定では完全にローカルで動かすことと、安全に機種を変更できることを両立する必要がある。

## Decision
OSの自動クラウドバックアップは既定で無効にする。暗号化した手動のエクスポートを使い、復元は、検証、候補の照合、プレビュー、確認、適用、検査の段階を踏んで行う。原本、APIキー、外部送信の許可、OSの権限は、既定では持ち運ばない。

## Consequences
機種を変えるときにユーザーがパスフレーズを管理し、復元のときにプレビューを確かめる手間が増える。その代わり、秘密情報や許可が意図せず持ち出されることを防げる。

## Rejected alternatives
暗号化していないJSONを通常のDownloadsへ定期的に書き出す方式、データベースのファイルを検証せずに置き換える方式。
