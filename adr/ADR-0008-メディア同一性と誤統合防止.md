# ADR-0008: メディア同一性と誤統合防止

- 日付: 2026-10-18
- 状態: Accepted（SQLite参照設計を検証済み、Room/Android実機は未実装）
- 関連: `../database/DATABASE_DESIGN.md` / `../docs/implementation/USE_CASES.md` / ADR-0005（3NF必須）

## Context
コピー、移動、再スキャンで永続Asset IDの正しさを守る。

## Decision
発見をmedia_discoveriesへ独立登録し、候補/根拠/決定を別関係とする。SHA256一致は候補でありリンク決定ではない。高信頼自動リンクはソース連続性が確認できる場合に限定。その他は新Assetまたはユーザー判断。

## Consequences
新規観測ごとに候補・根拠・決定の行が増え、曖昧な一致ではユーザー確認が必要になる。その代わり、コピーを誤って統合してユーザーメタデータを失う事故を防ぐ。

## Rejected alternatives
同じSHA256のメディアを自動統合する方式、MediaStore IDを永続Asset IDにする方式。
