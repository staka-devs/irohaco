# ADR-0011: 地図はMapLibreとOpenFreeMapで表示する

- 日付: 2026-10-21
- 状態: Accepted
- 関連: ADR-0002（外部APIは許可制）、PRD GAL-017・§10、ROADMAP M1-22

## Context
GPSのある写真と動画を地図の上に置き、撮影場所の地名をビューワーに出したい（GAL-017）。地図のタイルの取得と地名への変換は外部への通信になり、表示している範囲や撮影場所が提供元に伝わる。ライブラリと提供元を、ライセンス、APIキーの要否、オフラインの可否、送る内容の観点で選ぶ必要がある。

## Decision
- 地図はMapLibre Native Android（BSD）で描き、タイルとスタイルはOpenFreeMap（`https://tiles.openfreemap.org/styles/liberty`）から取る。APIキーは要らず、データはOpenStreetMap（ODbL）なので、地図上の帰属表示は消さない。
- 地名への変換はAndroid標準の`Geocoder`を使う。端末によっては、変換の要求がGoogleのサーバーに送られる。
- 最初に地図を開く前に、表示している範囲と撮影場所が提供元に伝わることを示し、許可を得る。許可は設定に保存し、設定の「オンライン地図の使用を許可」のスイッチでオンとオフを切り替えられる。許可がなければ地図の画面を開かず、地名への変換もしない。代わりに端末の地図アプリでの表示（M1-17）を案内する。
- `egress_grants`はAIの提供元と送る内容の種類を対象にした表なので、地図の許可はこの表に入れず、設定に置く。許可がなければ通信しないという点は、ADR-0002と同じ扱いにする。
- まとまり（クラスター）の計算は地図のライブラリに任せず、ドメインの層で行う。地図のライブラリを替えても同じまとまりを出し、テストできるようにする。

## Consequences
APIキーなしで地図を使え、Googleのサービスに依存しない。OpenFreeMapは無償で運営されており、提供が変わったり止まったりすることがあるため、スタイルのURLは1か所にまとめ、差し替えやすくする。オフラインの地図は今回作らない。

## Rejected alternatives
- osmdroidとOSMの公式タイル: OSMのタイルの利用規約はアプリからの大量の利用に向かない。
- Google Maps SDK（Maps Compose）: APIキーとGoogle Play開発者サービスが必須になり、表示範囲がGoogleに送られる。OpenFreeMapで足りるため、切り替えの選択肢としても置かない。
