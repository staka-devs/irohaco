# ADR-0006: 動画のシーン検索を初期リリースの必須機能とする
- 状態: Accepted
- 日付: 2026-10-18

## Context
ユーザーは動画のAI検索を初期の段階から求めている。動画全体を1つのベクトルにすると、短い場面を見落とす。

## Decision
動画を`video_segments`と`sampled_frames`に分け、各代表フレームを既定の画像Embeddingで索引にする。検索結果では動画のIDだけでなく該当するタイムスタンプを返し、プレイヤーはその位置へシークする。最初のインデックスはユーザーの操作でだけ始める。抽出の密度と、長い動画の時間のチャンクごとの処理の上限は、実機での評価で調整する（1本の動画に固定の上限は設けない）。

## Consequences
動画1本あたりのベクトルの数と計算の負荷は大きい。まず10秒間隔とシーンの検出による暫定の実装を計測し、短い場面を見落とすことがある点はカバレッジの表示で示す。将来、動画を直接Embeddingする方式に置き換えられるように、Portを保つ。
