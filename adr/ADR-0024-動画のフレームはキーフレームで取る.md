# ADR-0024: 動画は固定の間隔で区切り、フレームはMediaMetadataRetrieverのキーフレームで取る

- 日付: 2026-10-22
- 状態: Accepted
- 関連: ADR-0006（動画のシーン検索）、ADR-0021、ARCHITECTURE §2.2・§5.1、PRD §5.2、#33

## Context
動画の短い場面を探せるように、動画を区間に分け、区間ごとのフレームを写真と同じ空間に索引する（ADR-0006）。ARCHITECTUREではMedia3の`FrameExtractor`で時刻を指定してフレームを取り出し、シーンの変化を見つける処理と併用する設計にしている。

## Decision
- 動画は固定の時間幅で区間に分け、区間の中央のフレームを索引する。間隔は標準で10秒、詳細で3秒にする。1本の動画のフレーム数の上限はどちらも3時間分にする。
- フレームは端末の`MediaMetadataRetriever`で、指定の時刻にいちばん近いキーフレームを768ピクセルで取り出す。
- 品質ごとに別の抽出プロファイルにする。詳細で索引し直すと、標準のフレームを残したまま詳細のフレームが増える。
- シーンの変化で区切る処理と、近いフレームの重複を除く処理は、計測（AI_SEARCH_SPIKE）のあとに足す。

## Consequences
追加のライブラリなしで、動画のフレームを取り出せる。キーフレームを使うので、フレームの時刻は指定した時刻からずれることがある。検索の結果から再生するときは、フレームの時刻から再生する。どの品質のフレームも動画の終わりまで届いていない動画は、低カバレッジとして数える。

## Rejected alternatives
- Media3の`FrameExtractor`: 今は使っていない。キーフレームの時刻のずれが検索の精度に影響すると分かったら、切り替えを検討する。
