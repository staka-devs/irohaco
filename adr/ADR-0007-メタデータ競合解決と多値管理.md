# ADR-0007: メタデータ競合解決と多値管理

- 日付: 2026-10-18
- 状態: Accepted（SQLite参照設計を検証済み、Room/Android実機は未実装）
- 関連: `../database/DATABASE_DESIGN.md` / `../docs/implementation/USE_CASES.md` / ADR-0005（3NF必須）

## Context
DB内の編集を保持したまま外部のEXIF/XMP変更に追従する。

## Decision
metadata_override_sets + metadata_override_valuesでタグ単位の編集意図とoccurrenceを表現し、metadata_sync_baselinesとmetadata_conflictsで3-way mergeの根拠を保つ。基準値が不明な編集は自動マージしない。原本への反映は明示的に行う。

## Consequences
タグ単位の行と3-way比較の確認UIが増える。基準値の分からない編集は自動マージせず確認に回すため、ユーザー操作が発生しうる。

## Rejected alternatives
外部変更の度にローカルを上書きする方式、単一の巨大JSON値として保持する方式。
