# ADR-0009: アクセス権限と検索隔離

- 日付: 2026-10-18
- 状態: Accepted（SQLite参照設計を検証済み、Room/Android実機は未実装）
- 関連: `../database/DATABASE_DESIGN.md` / `../docs/implementation/USE_CASES.md` / ADR-0005（3NF必須）

## Context
Androidの部分アクセスと権限取り消しに伴う漏えいを避ける。

## Decision
OS権限状態を永続キャッシュして認可に使わない。メディアの閲覧、インデックス作成、検索結果、RAG、外部送信にライブアクセス判定を置く。イベント履歴は監査だけ。権限を失った画像は派生検索から除外し、ユーザー注釈は自動削除しない。外部APIは用途/接続先/ペイロードの許可も必要。

## Consequences
検索・RAG・送信の入口ごとにOSへの照会コストがかかる。権限を失った画像は検索結果から外れるが、ユーザー注釈は残る。

## Rejected alternatives
起動時だけ権限確認する方式、索引化済みなら許可が不要とする方式。
