# セキュリティとアクセシビリティのレビュー（M4-09）

- 対象: develop の `0706807`（M4-06 のエクスポートまで）と、M4-06 の復元の PR（#248）
- 方法: コードを読んで確かめた。実機での動作、TalkBack の読み上げ、文字を200%にしたときの表示、コントラストの実測は、まだ行っていない。
- 基準: PRD §10（セキュリティ・プライバシー）、DESIGN §7（アクセシビリティ）

## セキュリティ（PRD §10）

| 項目 | 結果 | 根拠 |
|---|---|---|
| ネットワークなしで使えること | 満たす | 通常のギャラリー、ローカルの索引、ローカルの RAG、OCR は通信しない。通信するのは、利用者が始めるモデルのダウンロード、外部のモデル、許可した後の地図のタイル、場所の名前の取得だけ。 |
| 外部への送信は用途ごとの許可が要ること | 満たす | 回答、Embedding、検索の送信は、送る前に毎回 `EgressPolicy` を確かめる。接続テストはアプリのサンプルだけを送る。 |
| 応答を命令として扱わないこと | 満たす | 応答は文と引用の番号として読むだけで、ファイルの削除や権限の変更につながる処理はない。 |
| 送る画像にメタデータを含めないこと | 満たす | 送る画像は縮小して JPEG に符号化し直すので、EXIF、XMP、GPS は残らない。 |
| 撮影日時と場所を許可なく送らないこと | このレビューで直した | 外部のモデルに質問するとき、撮影日時を文として送っていた。場所と同じく、外部のモデルには送らないようにした。 |
| 地図のタイルは最初に許可を得ること | 満たす | 既定は OFF で、最初に確認を出し、許可したときだけ地図を描く。 |
| 認証情報を Keystore で守ること | 満たす | API キーは AndroidKeyStore の鍵の AES-GCM で暗号化し、バックアップの対象外の場所に置く。エラーの文からはキーを伏せる。 |
| ログにキーや写真を出さないこと | このレビューで直した | 出荷するコードのログは2か所で、例外の本文に content URI やパスが入りうるものだった。例外の種類だけを出すようにした。 |
| HTTP の接続に警告し、既定は TLS にすること | 未解決 | 追加の画面では HTTP に警告を出す。ただし、アプリはクリアテキストの通信を許可していないため、HTTP の接続先には実際にはつながらない（推定。実機では確かめていない）。#249 で扱う。 |
| まとめて送る前に、件数、データ量、費用の見込みを示すこと | このレビューで直した | 件数に加えて、データ量の目安と、費用はプロバイダーの料金で決まりアプリには請求を止める仕組みがないことを示すようにした。 |
| OS のバックアップの対象外にすること | 満たす | `allowBackup="false"` と `dataExtractionRules` で、クラウドバックアップと端末間の転送の両方から除く。 |
| 公開しているコンポーネント | 満たす | 外から開けるのは MainActivity の content://media の表示だけで、MediaStore の ID か確かめてから使う。サービスと FileProvider は公開していない。 |
| WebView、動的なコードの読み込み、文字列で組み立てる SQL | 満たす | どれも使っていない。復元はファイルの列名を、表に実際にある列だけに絞ってから使う。 |

## アクセシビリティ（DESIGN §7）

| 項目 | 結果 | 根拠 |
|---|---|---|
| タッチターゲットを48dp以上にすること | 一部未達 | フォルダ、アルバム、タグのグリッドは満たす。タイムラインを10列以上に詰めると、セルが48dpより小さくなる。#250 で扱う。 |
| サムネイルの読み上げ | このレビューで直した | グリッドは種類、撮影日時、動画の長さ、選択の状態を読み上げる。位置情報履歴の画面の照合されなかった写真だけ、種類しか読み上げていなかったので、日時と長さを足した。 |
| 独自のジェスチャーの代わりの操作 | 一部未達 | グリッドの列の数はメニューでも変えられる。ビューアーの前後への移動と拡大は、スワイプとピンチでしかできない。#251 で扱う。 |
| 文字を200%にしたときのレイアウト | このレビューで直した | 高さを固定して文字を入れる箇所はない。1行に切り詰める文字のうち5か所が、何も示さずに切れていたので、省略記号を付けた。 |
| コントラスト | 実機で確かめる | 文字は基本的にテーマの色を使う。写真の上に重ねる白い文字（動画の長さなど）は、明るい写真の上で 4.5:1 を下回るおそれがある。#250 で実測する。 |
| アニメーションを減らす設定 | 未達 | 設定を見ているのは、ビューアーの GIF と動画の自動再生だけだった。サムネイルの選択、共有要素の遷移、画面の切り替えは、設定にかかわらず動く。#250 で扱う。 |
